# خطة تطوير «اكتشف الجزائر»

## النتيجة
- إنشاء صفحة `/discover` عصرية ومتكاملة تحافظ على خريطة الجزائر الحالية وتعرض الولايات حسب المنطقة ونوع السياحة.
- إنشاء صفحة تفاصيل موحّدة على `/discover/:id` مع معرض صور، نبذة، الموقع، الأنشطة، أفضل موسم، المدة المقترحة، الرحلات المتاحة، والوكالات الموثّقة.
- إبقاء روابط `/wilayas` الحالية عاملة حتى لا تنكسر أي ميزة أو رابط قديم.

## التنفيذ
1. توسيع بيانات الولايات الحالية بتصنيفات السياحة، معرض صور حقيقية، الموسم الأفضل، والمدة المقترحة، دون حذف البيانات القائمة.
2. تطوير الخريطة لتدعم اختيار الولاية بصريًا وتصفية الشرق/الوسط/الغرب/الجنوب مع وصول كامل بلوحة المفاتيح.
3. بناء واجهة اكتشاف ببحث، مرشحات الفئات السبعة، عدّاد نتائج، وبطاقات واضحة تحتوي الصورة والولاية والوصف وزر «اكتشف».
4. ربط صفحة التفاصيل ببيانات الرحلات المنشورة والوكالات الموثّقة الموجودة فعليًا، مع حالات تحميل وفراغ واضحة بدل اختلاق محتوى.
5. تحديث الروابط الرئيسية لتقود إلى `/discover` مع إبقاء المسارات القديمة متوافقة.
6. التحقق من العرض على الهاتف وسطح المكتب، ومن فتح صفحة وجهة والتصفية والروابط الفعلية دون أخطاء.

## تفاصيل تقنية
- استخدام نفس نظام الألوان والخطوط الحالي ومكوّنات الأزرار الموجودة.
- إضافة مساري TanStack جديدين: `/discover` و`/discover/$id`، مع بيانات وصفية مستقلة لكل صفحة.
- مطابقة الرحلات والوكالات بالولاية عبر أسماء الوجهات الحالية، دون تغيير الجداول أو سياسات الحماية.
- تسجيل قرار التوافق بين المسارات القديمة والجديدة في ملف قرارات المشروع.
