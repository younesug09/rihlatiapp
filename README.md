# Rahalati: Your Journey Awaits

Create a modern Arabic travel application called "رحلتي".

The app is designed as a tourism and media communication platform for a university master graduation project in Mass Communication.

Main Features:

- Beautiful modern Arabic UI

- Tourism destinations in Algeria and worldwide

- Destination details with images and descriptions

- Travel booking system

- User authentication

- User reviews and ratings

- Tourism news section

- Media gallery for photos and videos

- Search and filtering system

- Favorite destinations

- Notifications

- Admin dashboard

Design:

- Elegant and modern

- Mobile-first responsive design

- Arabic RTL support

- White and blue theme

- Smooth animations

Pages:

1. Splash Screen

2. Home Page

3. Explore Destinations

4. Destination Details

5. Booking Page

6. Tourism News

7. User Profile

8. Favorites

9. Admin Dashboard

Backend:

- Supabase

Extra:

- Add tourism communication and digital media style

- Inspired by Airbnb and Booking.com
